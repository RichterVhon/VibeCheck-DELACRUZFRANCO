# VibeCheck-DELACRUZFRANCO
WEB ENG LABORATORY ACTIVITY 3 - DELA CRUZ, R.V., FRANCO, J.C.

STEPS TO RUN:

NOTE: Node modules are already included in the repository. No need to install extra npms.

1. Run backend in a separate terminal window (ex. Command Prompt) using node index.js, make sure you are in the backend/ directory.
NOTE: Output should be like this: VibeCheck API running at http://localhost:3000
NOTE: Everytime you make changes to the backend you should restart the server using Ctrl+C and run node index.js again.

2. Running Frontend (No Live Server)
If you do not have the VS Code Live Server extension, using this method:

Navigate to your frontend/ folder in your computer's File Explorer (Windows) or Finder (Mac).
Double-click index.html. It will open in your default web browser.

NOTE: If you have live server, you can just right click index.html file then choose "Open with Live server".
NOTE: For sanity, everytime you make changes in the frontend make sure to refresh the page browser.
